# Screenshot plan

Product screenshots will be added only after they pass this privacy checklist.

## Planned views

1. Daily relationship dashboard
2. Prioritized work queue
3. Company 360 view
4. Relationship timeline
5. Daily briefing
6. Sales insights

## Privacy checklist

- Use synthetic people, companies, messages, and opportunities
- Remove email addresses, phone numbers, profile URLs, and personal notes
- Remove customer and workspace names
- Remove local paths, database names, and configuration values
- Remove browser bookmarks, account menus, notifications, and other unrelated personal UI
- Review every visible label and data value at full resolution
- Confirm that no source code, credentials, tokens, or private URLs are visible

Until sanitized images are available, this folder contains guidance only.
