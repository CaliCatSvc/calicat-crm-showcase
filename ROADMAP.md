# Product roadmap

The roadmap reflects likely next investments, not promised release dates.

## Showcase readiness

- Build a fully synthetic demonstration dataset
- Capture sanitized product screenshots
- Record a short product walkthrough
- Add a concise product story for recruiters and potential users

## Product experience

- Improve first-run setup and guided onboarding
- Add saved views for common daily workflows
- Expand accessibility support
- Refine mobile interaction patterns
- Add clearer empty states and contextual help

## Engineering quality

- Split large internal modules into clearer ownership boundaries
- Add browser-based end-to-end tests
- Add automated accessibility checks
- Add performance benchmarks
- Introduce a formal migration ledger

## Scale and integrations

- Add pagination for large record collections
- Batch relationship and analytics queries
- Add optional calendar, email, and prospecting integrations
- Preserve local-first storage and explicit user control

## Intelligence

- Improve explanation quality for recommendations
- Add configurable scoring inputs
- Expand relationship coverage and opportunity-risk signals
- Keep deterministic fallbacks for core workflows
